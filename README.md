# لعبة كاشير رش 🛒

لعبة كاشير تفاعلية باللغة العربية. درّب نفسك على حساب إجمالي الفاتورة والباقي للعميل بسرعة ودقة.

## تشغيل اللعبة
افتح ملف `index.html` في أي متصفح حديث. اللعبة لا تحتاج إلى تثبيت أو إعداد خادم.

## نشر اللعبة على GitHub Pages
1. أنشئ مستودعًا جديدًا (Repository) على GitHub.
2. ارفع الملفين `index.html` و`README.md` إلى المجلد الرئيسي للمستودع.
3. افتح **Settings → Pages**.
4. في قسم **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
6. بعد اكتمال النشر سيظهر رابط اللعبة في صفحة GitHub Pages.

## ملاحظات
- تصميم متجاوب مع شاشات الكمبيوتر والموبايل.
- واجهة اللعبة باللغة العربية واتجاهها من اليمين إلى اليسار.
- قد تحتاج خطوط Google Fonts إلى اتصال بالإنترنت؛ وتعمل اللعبة حتى بدونها باستخدام الخطوط البديلة.
